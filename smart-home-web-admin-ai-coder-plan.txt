API RULES
================================================

Backend is the source of truth.

Before implementing a feature:
1. Inspect Swagger/OpenAPI.
2. Inspect DTOs/API responses when necessary.
3. Use actual endpoints.
4. Use actual request/response shapes.
5. Do not invent backend behavior.
6. Do not change backend contracts only for frontend convenience.

If a real backend contract problem is found:
- report it
- identify the cause
- make the smallest appropriate change
